# Materiales y hardware de referencia

Fuente: SRR inglés revisión 5, selección D1 y traducción española. S identifica referencia seleccionada por el equipo. Las alternativas son respaldo. No se afirma disponibilidad, compra, compatibilidad de ensamblaje ni calificación de vuelo. Confirmar variante, cotización, masa y prestaciones bajo las condiciones de cada uso.
