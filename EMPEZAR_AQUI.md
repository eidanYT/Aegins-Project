# Empezar a trabajar

## Si eres integrante

1. Entra en [tu módulo desde la página principal](README.md#entra-en-tu-módulo-y-empieza).
2. Lee su Get started y completa `propuesta.md` en una rama.
3. Comparte un PR con preguntas concretas para los otros módulos.
4. Continúa avanzando con supuestos marcados mientras reciben revisión.

No necesitas esperar una reunión, una fecha del plan ni un Project configurado. Consulta [la guía práctica](CONTRIBUTING.md) para editar desde el navegador y [colaboración](management/colaboracion.md) para acuerdos entre módulos.

## Preparación del equipo

- Completar responsables pendientes y usuarios reales en [equipo](management/equipo.md).
- Comprobar que los integrantes pueden acceder y proponer cambios.
- Confirmar agenda y entregables; actualizar [hitos](management/plan.md).
- Revisar misión, plataforma y pieza de referencia; los borradores pueden elaborarse mientras se acuerdan.
- Designar quién coordina la integración y las revisiones de módulos sin responsable.

## Revisión de cambios

Ningún cambio técnico importante se integra sin revisión de otra persona. Las interfaces requieren conformidad de todos los afectados y coordinación de sistemas. Si una persona cubre ambos lados, incluir revisor independiente.

Si están disponibles, las reglas de `main` pueden exigir PR y aprobación; la revisión documentada sigue siendo necesaria. `CODEOWNERS.example` es un ejemplo inactivo: solo activar tras sustituir usuarios y comprobar permisos. Varios propietarios en una línea no garantizan la revisión de todos.

## Palabras de GitHub

| Palabra | Significado práctico |
|---|---|
| Repositorio | Archivos del proyecto y su historial |
| Rama / branch | Espacio para preparar una propuesta |
| Commit | Versión guardada con explicación |
| Issue | Tarea, pregunta o decisión a seguir |
| PR / pull request | Propuesta de incorporar archivos o cambios |
| Review | Revisión de otra persona |
| Merge | Incorporación del cambio a la rama compartida |
| main | Rama que contiene la versión compartida |
| ICD | Documento de acuerdo entre módulos |
| TBD / TBR | Por determinar / propuesto y pendiente de revisión |
