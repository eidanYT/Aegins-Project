# FORGE-UG — AEGINS

Proyecto de impresión 3D en microgravedad. Este repositorio reúne el concepto, los modelos, las interfaces y la preparación del SRR.

## Entra en tu módulo y empieza

**Puedes trabajar desde ahora. Las fechas del plan son hitos de revisión o entrega, no fechas para empezar.**

1. Abre tu módulo: su README explica tu primera entrega y dónde escribirla.
2. Completa su archivo `propuesta.md` en una rama de trabajo. Ya tiene una estructura para empezar.
3. Puedes proponer un modelo completo de tu módulo o del sistema. Marca los supuestos y las partes de otros módulos como pendientes de revisión.
4. Comparte un pull request (PR): los demás revisan cuando estén disponibles. Continúa con lo que puedas avanzar mientras llega su respuesta.

Los nombres identifican a los responsables; cualquier integrante puede aportar a otro módulo mediante una propuesta revisada.

## Cómo sabemos qué está acordado

**TBD:** falta determinarlo. **TBR:** propuesta pendiente de revisión. **APROBADO:** acuerdo técnico registrado. **VERIFICADO:** comprobado por el método y la evidencia indicados; una revisión de texto no verifica el comportamiento físico.

Cada propuesta indica unidades, fuentes, supuestos y preguntas para otros miembros. Las conformidades se registran en GitHub y luego se incorporan al documento correspondiente.

**Estado del proyecto:** concepto en desarrollo. La plataforma y sus condiciones se definen en la misión; el hardware candidato y los ejemplos numéricos no son selecciones definitivas ni evidencia de vuelo.
